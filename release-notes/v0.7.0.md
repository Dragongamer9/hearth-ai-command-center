### What's new in 0.7.0
- **One task at a time per AI:** each AI works through its own queue. While it's busy, a task's button reads **Start next** and stays clickable; started tasks run in the order you pressed Start. A task you only **Add** never starts by itself.
- **Out of usage, no waiting:** when an AI runs out of usage, its waiting tasks move to the next free AI with the same kind of role.
- **Clear owner buttons on the Task board:** **Approve to merge**, **Approve to resume** and **Approve to start**, each with the reason it's waiting for you. Finished work goes straight to its reviewer, so nothing sits at Checkpoint.
- **Reviewers sign off in chat:** the assigned reviewer writes `APPROVE: T-…` (task moves to Approvals) or `CHANGES: T-… reason` (back to the implementer).
- **"Done" means a commit and test results:** a done report is tied to the branch's newest commit and shows "tests passed / failed / not run" on the board and in Approvals. It's sent back if the tests failed or nothing was committed since a review asked for changes. An approval covers that exact commit; if the branch changes, the task goes back to review. "Done" never means "pushed".
- **Fewer merge conflicts:** **Update from main** brings a task branch up to date before you approve, and **Combine into a release branch** merges several approved tasks onto a new `release/…` branch (never main) and lists any conflicts.
- **Duplicate check:** a new task that looks like an open one offers **Open T-…** or **Add anyway**.
- **Let the lead act for you (off by default):** a Settings switch lets the lead (Claude) approve, deny, start and add tasks. It can't approve its own unreviewed work; releases, tags and version numbers stay yours; every action is in Team chat and the Audit log, with **Undo** where possible.
- **Lead handles GitHub:** a Settings toggle (on when GitHub is already set up) lets the lead pull, push task branches and merge approved tasks onto `release/next`, using your own git/gh sign-in. Each push and pull shows in Team chat and the Audit log. Main stays protected and it never makes tags or releases.
- **Images and video in Team chat:** paste, drag or attach png, jpg, webp, gif, mp4, webm or mov (up to 200 MB). AIs can post screenshots and recordings too with an `ATTACH:` line. Images go to the AIs whose tools can read them; videos as still frames when ffmpeg is installed. Files only go to the AI tools you already use.
- **You can always type:** Send is never blocked. Writing while the AIs are answering stops the ones that haven't started and restarts with your message; a **Stop** button ends the round.
- **Turn-taking by default:** the lead answers first and others join when mentioned or handed off. Mention two or more AIs, or write @everyone, and they answer at the same time, each reply labeled.
- **Team status panel** above the chat: ready, busy, out of usage (until about when) or needs sign-in.
- **Quiet chat:** an AI that isn't signed in or has a bad key shows one badge instead of an error every round, and a rejected key stays "API key rejected" after Re-check or a restart until you change it.
- **API key Test button** on the Agents page; a key you pasted but haven't saved stays in the box.
- **Gemini through Google's Antigravity CLI (`agy`)** when it's installed, with its own sign-in check. Full access skips agy's permission prompts; very long prompts are trimmed to fit, keeping the newest messages.
- **Local AI** knows it has no tools, doesn't repeat teammates and doesn't claim work it can't do.
