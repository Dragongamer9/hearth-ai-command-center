### What's new in 2.6

## Your GPU server and Uncensored mode

- **Your GPU server is now told that adult content is allowed** while Uncensored mode is on: "sexual content between adults is allowed in this chat." Before, it was only given the limits, so models played it safe and refused anything adult.
- **Nothing else changed.** The limits stay as before, nothing changes while Uncensored mode is off, and no other AI is told this.
- **Tip:** start a new chat with your GPU server after updating, so it doesn't copy refusals from older messages.
