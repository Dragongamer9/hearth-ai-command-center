### What's new in 2.5

## Your GPU servers pick up their models by themselves

- **A model list for each server.** Settings › Accounts › Your GPU servers now shows a dropdown on each server's row with every model that server has. Picking one saves it straight away. The server's address, key and your other servers stay as they are.
- **Refresh** looks again after you download a new model on the server.
- **Adding a server:** type its address and the model list fills in by itself. Nothing else needs typing.
- **Works with** OpenAI-compatible servers, Ollama (including ones that only answer on /api/tags) and ComfyUI (its checkpoints).
- **No model picked:** the server uses the first model it has. Before, the app asked for one called "default", which Ollama refuses.
