### What's new in 0.6.0
- **One-click install for every AI:** press **Install** on any AI and its official tool is installed for you in a terminal you can see, then its own sign-in opens by itself. No installers to hunt down.
- **Install all:** one button on the Agents page installs every AI tool you don't have yet, one after another, with a summary of what worked.
- **No password needed:** if Node.js or uv is missing, it's set up for you in your own folder. Node.js comes from nodejs.org and is checked against its official checksum before it's used.
- **Local AI (Ollama):** installs with Ollama's official installer, which asks for your computer password in the terminal. The app never sees it. Install all only includes Ollama if you tick it.
- **Clear progress:** every card shows Install, Installing… or Installed, and says so if an install failed.

### Also in this release (0.5.0 wasn't published separately)
- **Now a .deb too:** install it on Debian, Ubuntu or Hearth OS with your package manager (`sudo apt install ./hearth-ai-command-center_0.6.0_amd64.deb`), or keep using the AppImage.
- **Hearth OS 1.0 look:** Steam-style design with light mode. It follows your Hearth theme live when one is set.
- **Agents, compact:** a tidy roster with details on demand, and one-click official sign-in that shows its progress (install, browser sign-in, linked).
- **More teammates:** Grok, Mistral, Qwen, Perplexity and DeepSeek. Copilot and Meta AI open as windows of their own sites.
- **Chat history:** continue Claude Code, Codex, Gemini, Qwen and Grok sessions in either place, import your official ChatGPT, Claude, Gemini and DeepSeek exports, and search them all.
- **Team chat:** AIs post, mention and hand off work, can edit or take back their own messages, and ask your permission with Approve / Deny / Ask why cards. You can edit or delete any message.
- **GitHub:** pull request tracking (status, checks, reviews), merges only when you approve, and releases only with a version you type.
- **Overview and Board** show active work, who's doing what, and recent chat.
- **No crash** when an AI tool closes before reading the message sent to it.
- Node.js 20 or newer is now required (Gemini CLI and Qwen Code need it); the app sets it up for you if it's missing.

AppImage: update from inside the app (Settings → App updates → Check for updates). The .deb updates when you install the newer .deb.
