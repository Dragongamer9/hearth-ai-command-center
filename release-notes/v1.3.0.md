### What's new in 1.3

**Switching projects**
- The project name at the top left is now a switcher: click it to see your projects (the open one has a check), switch to another, or add a project folder. It works with the sidebar narrowed too, where the project list was hidden before.
- A click on a project always answers: "Switching to …" right away, or why it couldn't (for example, which running task to finish or stop first).
- Fixed: an AI run that failed in an unusual way could leave its task marked as running for the rest of the session, which quietly blocked switching projects until the app was restarted.
- Fixed: stray letters of the app name showing at the top of the narrowed sidebar.

AppImage: update from inside the app (Settings → App updates → Check for updates).

.deb installs update from inside the app too (asks for your computer password once per update).
