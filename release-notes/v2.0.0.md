### What's new in 2.0

## Fixed: keys now save on every PC with a keyring

- **API keys now save on PCs where only the newer keyring works** (the Secret portal, the Secret Service or KWallet). Before, the app only used the older way of reaching the keyring, so on those PCs it said "Encryption is not available" and the key wasn't kept.
- **Keys you saved with older versions still work.** They are moved to the newer way the next time they are used.
- **If your PC has no keyring at all,** the app now says so plainly and saves nothing. You can choose **basic protection** yourself in Settings › Accounts. It is weak, so the app only uses it when you pick it, and it shows that it's on.

## Open-source voices: a wide range of free, realistic voices

Voice chat can now use the free, open-source voice engines running on your own PCs: **Kokoro, Chatterbox, Sesame CSM, Dia, CosyVoice2 and Orpheus**. They run on this PC or on your Nvidia home server (RTX 5070) over Tailscale. They cost nothing, and the reply text goes only to your own machine.

- **Add a speech server in Settings › Voice.** Give it a name, pick the server program, and type its address. A key is optional; it is saved encrypted on this PC, never in your settings, and sent only to that server.
  - Server programs you can pick, each with its usual port filled in: **Kokoro-FastAPI** (8880), **chatterbox-tts-api** (4123), **Chatterbox-TTS-Server** (8004), **Dia-TTS-Server** (8003), **Orpheus-FastAPI** (5005), **sesame_csm_openai** (8000) and **CosyVoice's own server** (50000).
  - Anything else that speaks the **OpenAI-compatible speech API** works too: pick that and the engine it runs.
  - Hearth OS 1.4's Home server can run Kokoro-FastAPI for you: point the app at it on port 8880.
- **Test button:** it lists the server's voices and speaks a short line, so you hear it right away. If something is wrong, it tells you which step failed and why (the server is off, the key was refused, the address is wrong).
- **Each server shows its voices** and becomes a voice provider next to ElevenLabs, OpenAI and This PC.
- **Mix engines.** Any teammate, the narrator, the default voice or a character can use any server's voices. For example, a Dia narrator, Kokoro for one character and Chatterbox for another.
- **Expressive cues** for the engines that perform them, shown as hints in Settings › Voice:
  - **Dia:** [S1] and [S2] for two speakers, and cues like (laughs), (sighs) or (clears throat).
  - **Orpheus:** <laugh>, <chuckle>, <sigh>, <gasp> and more.
  - **Chatterbox:** an Exaggeration setting for how emotional it sounds.
  - For voices that don't perform cues, the cues are left out instead of being read aloud.
- **Add your own voice on a server** (chatterbox-tts-api, the Sesame server and CosyVoice2). This uses the same rule as ElevenLabs: only after you tick the box saying it's your own voice or you have the speaker's permission.
- **Safe by design:**
  - The app only ever talks to the addresses you saved.
  - It never follows a redirect, so your key can't be sent anywhere else.
  - Every request has a time limit, and audio is size-capped.
- **Venice, Civitai and your GPU server stay private:** their replies may be spoken on your own speech servers, and they still never go to OpenAI unless you allowed it.
- **Credits:** each engine and server program is listed with its licence in Settings › App updates › Credits. The app only talks to these programs over HTTP; none of their code is inside it.
